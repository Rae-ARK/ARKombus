# ARKombus

A Bluetooth hands-free phone for the Linux desktop: your phone connects
over HFP, and ARKombus gives you calls, a dialer, contacts and call
history on your computer.

The frontend is built with [ARKlight](https://github.com/Rae-ARK/ARKlight)
and the backend is Flask.

## Status

ARKombus is in its early planning stage. This page deliberately states
no version numbers, feature lists, install steps or architecture of its
own, so it cannot fall out of date.
