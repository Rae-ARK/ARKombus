# Foundational

## Overview

The core reading for understanding how ARKombus works and why it's built
the way it is: architecture, design rationale, and the decisions that
are in force today. This is reference material for the project as a
whole, not a record of a single in-flight task.

**These docs are not deletable.** Unlike the working-reference docs
elsewhere in `docs/`, files in this folder are the permanent design
record for ARKombus. They get updated as the project evolves, but a file
in this folder should never simply be deleted once its "purpose" is
fulfilled -- there is no expiry condition for foundational design
knowledge.

Everything in here is *settled*: a reader landing here should be able to
trust that it describes the project as it actually is, without having to
work out which files are aspirational. Unsettled ideas live in
[`../proposal/`](../proposal/README.md); accepted but unbuilt work lives
in [`../implementation/`](../implementation/README.md).
