# Frontend

The ARKombus user interface, written with
[ARKlight](https://github.com/Rae-ARK/ARKlight) and compiled to static
HTML, CSS and JavaScript that the Flask backend serves.

This folder is a stub for now. What the frontend covers, its screens,
and how to build it are recorded in [`docs/`](../../docs/README.MD), not
here, so this page cannot go stale.
